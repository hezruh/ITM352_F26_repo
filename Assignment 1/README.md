●      Data Structure Justification: What data structure design was used to store the quiz questions and why is the best for the application? Explain the design quality goals for this? E.g. readability by human, easy to read from a file, etc. Do not simply list the goals. Explain them relative to storing quiz questions.

    At its core, the base data structure design that was used to store the quiz questions was a dictionary. In the file questions.json, each question was stored as a key, with the corresponding multiple choice answers being stored as a list of strings. This design is best for the application because by utilizing a dictionary, there is a clear, straightforward way to associate the questions we are providing to the user with their respective answers. While optimized for readability by a program from a json file, it is also more maintainable and easier to update than a long list or tuple. However, more than all of that, I would argue that utilizing a dictionary in this way makes it the absolute easiest way to read and quickly understand the questions and answers to the quiz by a human. Simply being able to go in to the Json file, jump to the exact question you would like to edit, then immediately find the associated possible answers makes the process of updating the quiz profoundly efficient.

    The main part of the application that handles invalid user inputs is the while loop that starts on line 17 of the ask_question function. By utilizing a while loop in my program, I am able to trap my user in a loop that will not allow them to progress with the quiz until they provide a valid input (such as a, b, c, d, or, if they still have it, the 50/50 option).
